
# api服务启动说明
```
# 默认启动（端口8000）
python -m ultrasoundrag.api

# 指定端口启动
python -m ultrasoundrag.api --port 8001

# 指定主机和端口
python -m ultrasoundrag.api --host 0.0.0.0 --port 8000

# 启用自动重载（开发模式）
python -m ultrasoundrag.api --reload

# 指定工作进程数
python -m ultrasoundrag.api --workers 4
```

# web端启动说明
```
# 默认启动（端口8501）
python -m ultrasoundrag.web

# 指定端口启动
python -m ultrasoundrag.web --port 8502

# 指定主机和端口
python -m ultrasoundrag.web --host 0.0.0.0 --port 8501

# 自动打开浏览器
python -m ultrasoundrag.web --open-browser
```

# 数据库管理说明

## 场景1：重构所有集合（完全重建）
```
# 重建所有索引（删除并重新创建所有数据）
python -c "
from ultrasoundrag.core.indexing import build_all_indexes
result = build_all_indexes(recreate=True)
print('重构完成:', result)
"

# 仅重建Markdown索引
python -c "
from ultrasoundrag.core.indexing import build_markdown_index
result = build_markdown_index(recreate=True)
print('Markdown索引重构完成:', result)
"

# 仅重建图片索引
python -c "
from ultrasoundrag.core.indexing import build_image_index
result = build_image_index(recreate=True)
print('图片索引重构完成:', result)
"
```

## 场景2：添加新文件到集合（增量更新）
```
# 增量更新所有数据集（只添加新文件，不删除现有数据）
python -c "
from ultrasoundrag.core.indexing import update_documents_incremental
result = update_documents_incremental()
print('增量更新完成:', result)
"

# 增量更新指定数据集
python -c "
from ultrasoundrag.core.indexing import update_documents_incremental
result = update_documents_incremental(target_datasets=['ultrasound_book'])
print('指定数据集增量更新完成:', result)
"

# 指定完整路径更新单个文档
# 注意ultrasound_book这个是数据集的配置就是检索里面那个！
python -c "
from ultrasoundrag.core.indexing import update_single_document
success = update_single_document('/media/ps/data-ssd/UltrasoundRAG/UltrasoundRAG/data/thyroidagent/markdown/甲状腺.md', 'ultrasound_book')
print('单个文档更新完成:', success)
"
```

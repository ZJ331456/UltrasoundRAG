# UltrasoundRAG 多模态检索流程图

## 🔍 整体检索流程

```
输入层
  ↓
[文本查询 + 图片路径]
  ↓
预处理层
  ↓
[输入验证] → [图片预处理] → [文本增强]
  ↓
向量化层
  ↓
[文本向量化] ← → [图片向量化]
  ↓        ↓
[Qwen向量] [CLIP向量]
  ↓
检索层（并行执行）
  ↓
┌─────────────┬─────────────┬─────────────┬─────────────┐
│   T2T检索   │   T2I检索   │   I2T检索   │   I2I检索   │
│ 文本→文本   │ 文本→图片   │ 图片→文本   │ 图片→图片   │
│   60%权重   │   20%权重   │   15%权重   │    5%权重   │
└─────────────┴─────────────┴─────────────┴─────────────┘
  ↓
融合层
  ↓
[自适应权重调整] → [结果去重] → [分数归一化] → [初步排序]
  ↓
增强层
  ↓
[多模态重排序] → [Caption增强] → [CrossEncoder排序]
  ↓
输出层
  ↓
[结构化结果] → [性能统计] → [返回给用户]
```

## 📊 详细流程分解

### 1️⃣ 输入预处理阶段
```
用户输入: "心脏超声检查方法" + cardiac_image.jpg
    ↓
安全检查 → 格式验证 → 内容解析
    ↓
预处理结果: 标准化文本 + 预处理图片
```

### 2️⃣ 向量化阶段
```
文本: "心脏超声检查方法"
    ↓
[Qwen嵌入模型] → 1024维文本向量
[CLIP文本编码器] → 768维文本向量
    ↓
图片: cardiac_image.jpg
    ↓
[CLIP视觉编码器] → 768维图片向量
```

### 3️⃣ 并行检索阶段
```
T2T检索 (权重60%)
    ↓
文本向量 → Milvus文本集合 → 相关文档片段
    ↓
结果: 4个文本结果

T2I检索 (权重20%)
    ↓
文本向量 → Milvus图片集合 → 相关图片
    ↓
结果: 2个图片结果

I2T检索 (权重15%)
    ↓
图片向量 → Milvus文本集合 → 描述图片的文本
    ↓
结果: 3个文本结果

I2I检索 (权重5%)
    ↓
图片向量 → Milvus图片集合 → 相似图片
    ↓
结果: 1个图片结果
```

### 4️⃣ 智能融合阶段
```
自适应权重调整:
    ↓
检测到"检查方法" → 提升文本检索权重 (+0.2)
检测到图片内容 → 提升图像检索权重 (+0.1)
    ↓
调整后权重: T2T(65%), T2I(25%), I2T(7%), I2I(3%)
    ↓
加权合并结果:
    ↓
去重处理 → 移除重复内容
    ↓
分数归一化 → 统一相似度分数
    ↓
初步排序 → 按综合分数排序
```

### 5️⃣ 增强重排序阶段
```
多模态重排序:
    ↓
[CLIP跨模态计算] → 文本-图片相似度
[CrossEncoder模型] → 精细排序
[规则重排序] → 业务逻辑排序
    ↓
Caption增强:
    ↓
提取图片标题 → 语义匹配 → 相关性提升
    ↓
最终排序 → 综合多种排序结果
```

### 6️⃣ 结果输出阶段
```
结构化输出:
{
    "query": "心脏超声检查方法",
    "image_query": "cardiac_image.jpg",

}
```

## 🎯 关键优化点

### ⚡ 性能优化
- **并行处理**: 四种检索方式同时执行
- **智能缓存**: 向量和结果缓存
- **组件复用**: 共享模型和连接
- **批处理**: 批量向量化处理

### 🧠 智能优化
- **自适应权重**: 根据查询特征动态调整
- **领域感知**: 支持医学领域分区
- **多模态融合**: 文本和图像信息互补
- **语义增强**: Caption和标题匹配

### 🔒 企业级特性
- **安全认证**: API Token验证
- **异常处理**: 统一错误管理
- **性能监控**: 实时性能统计
- **可扩展性**: 模块化架构设计

## 📈 性能指标

## 🔧 配置选项

### 基础配置
```python
retriever = create_enhanced_multimodal_retriever(
    db_name="medical_db",           # 数据库名称
    top_k=10,                       # 返回结果数量
    similarity_threshold=0.3        # 相似度阈值
)
```

### 高级配置
```python
retriever = create_enhanced_multimodal_retriever(
    enable_dynamic_weights=True,    # 启用自适应权重
    enable_domain_partition=True,   # 启用领域分区
    enable_caption_enhancement=True, # 启用Caption增强
    enable_multimodal_rerank=True,  # 启用多模态重排序
    fusion_strategy="adaptive_smart" # 融合策略
)
```

这个检索系统通过多模态融合和智能优化，能够为用户提供高质量、高相关性的检索结果！

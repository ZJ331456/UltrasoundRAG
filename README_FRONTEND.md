## 功能特性

### 支持的检索模式

1. **T2T (文本→文本)** - 文本知识检索
2. **T2I (文本→图片)** - 根据描述找图片
3. **I2T (图片→文本)** - 上传图片找相关文本
4. **I2I (图片→图片)** - 上传图片找相似图片
5. **Caption (标题→图片)** - 精确标题匹配
6. **混合检索** - 多种模式同时执行

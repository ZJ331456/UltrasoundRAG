## 系统架构

```
查询输入 → 检索器选择 → 向量化 → Milvus检索 → 结果融合 → 重排序 → 输出结果
   ↓           ↓         ↓        ↓         ↓        ↓
文本查询    T2T/T2I    文本向量   文本集合   智能融合   规则/模型
图像查询    I2T/I2I    图像向量   图像集合   去重排序   重排序
```

## 详细组件说明

### 1. 模块化检索器 (ModularRetrievers)

#### 功能描述
提供四种独立的检索方式，每种检索器都可以单独使用，支持灵活的配置和扩展。

#### 核心特性
- **完全独立**: 每种检索方式完全独立，可单独使用
- **配置驱动**: 基于RetrievalContext的灵活配置
- **多数据库支持**: 支持不同数据库和集合
- **领域过滤**: 支持按领域分区检索
- **统一接口**: 提供一致的检索接口

#### 主要类和方法

##### `RetrievalContext`
检索上下文配置类，定义检索的基本参数。

```python
@dataclass
class RetrievalContext:
    db_name: str                    # 数据库名称
    text_collection: Optional[str]  # 文本集合名称
    image_collection: Optional[str] # 图像集合名称
    top_k: int = 10                # 返回结果数量
    milvus_uri: Optional[str] = None
    milvus_token: Optional[str] = None
    domain: Optional[str] = None   # 领域过滤
    use_partition: bool = False    # 是否使用分区
    # —— 增强开关 ——
    enable_dynamic_weights: bool = True
    enable_domain_partition: bool = True
    enable_caption_enhancement: bool = True
    enable_fusion_optimization: bool = True
    enable_multimodal_rerank: bool = True
```

##### `T2TRetriever` - 文本到文本检索器

**功能**: 在文本集合中进行语义检索，返回相关文本内容。

**主要方法**:
- `search(query: str, top_k: Optional[int] = None) -> List[RetrievalResult]`
- `search_with_filters(query: str, filters: Dict[str, Any]) -> List[RetrievalResult]`

**使用示例**:
```python
from UltrasoundRAG.retrival import create_t2t_retriever

# 创建T2T检索器
t2t_retriever = create_t2t_retriever(
    db_name="ultrasound_rag",
    top_k=10
)

# 执行检索
results = t2t_retriever.search("心脏超声检查方法")
for result in results:
    print(f"内容: {result.content[:100]}...")
    print(f"分数: {result.score}")
```

##### `T2IRetriever` - 文本到图像检索器（增强版）

**功能**: 基于文本查询在图像集合中检索相关图像。

**主要方法**:
- `search(query: str, top_k: Optional[int] = None) -> Dict[str, Any]`

返回字典包含：`results`（List[RetrievalResult]）、`domain_filter`、`partitions`、`response_time`。

说明：内部使用 CLIP 文本编码对图像集合的 `image_vector` 进行检索，并可按配置进行相似度阈值过滤、Caption 语义增强与多模态重排序。

**使用示例**:
```python
from UltrasoundRAG.retrival import create_t2i_retriever

# 创建T2I检索器
t2i_retriever = create_t2i_retriever(
    db_name="ultrasound_rag",
    top_k=5
)

# 执行检索
res = t2i_retriever.search("心脏横切面图像", top_k=5)
for result in res.get('results', []):
    print(result.metadata.get('image_path'), result.metadata.get('caption'))
```

##### `I2TRetriever` - 图像到文本检索器（增强版）

**功能**: 基于输入图像检索相关文本描述。

**主要方法**:
- `search(image_path: str, top_k: Optional[int] = None) -> Dict[str, Any]`

返回字典包含：`results`（List[RetrievalResult]）、`matched_images`（从文本结果反向匹配回图像的简化 like 匹配结果）、`matched_image_count`。

**使用示例**:
```python
from UltrasoundRAG.retrival import create_i2t_retriever

# 创建I2T检索器
i2t_retriever = create_i2t_retriever(
    db_name="ultrasound_rag",
    top_k=10
)

# 执行检索
res = i2t_retriever.search("/path/to/heart_image.jpg", top_k=10)
for result in res.get('results', []):
    print(result.content[:100])
print("matched images:", res.get('matched_image_count', 0))
```

##### `I2IRetriever` - 图像到图像检索器（增强版）

**功能**: 基于输入图像检索相似图像。

**主要方法**:
- `search(image_path: str, top_k: Optional[int] = None) -> Dict[str, Any]`

返回字典包含：`results`（List[RetrievalResult]）、相似度阈值过滤说明。

**使用示例**:
```python
from UltrasoundRAG.retrival import create_i2i_retriever

# 创建I2I检索器
i2i_retriever = create_i2i_retriever(
    db_name="ultrasound_rag",
    top_k=5
)

# 执行检索
results = i2i_retriever.search("/path/to/heart_image.jpg")
for result in results:
    print(f"相似图像: {result.metadata.get('relative_path')}")
    print(f"相似度: {result.score}")
```

### 2. Caption检索模块 (CaptionToImageRetriever)

#### 功能描述（现行实现）
提供精简、稳定的接口：直接使用 MD 文档中 `image_captions` 字段（列表或其 JSON 字符串）对图像集合的 `caption` 字段进行 OR-like 匹配，便于从文本块关联到对应图片。

#### 核心特性
- **统一清洗**: 自动去除编号前缀（如“图1-2”、“Figure 2.3”）与“注：/Note:”段落
- **智能拆分**: 按中文/英文分隔符（，,；;、）拆分为候选短语
- **一次性匹配**: 将候选短语以 OR 的 like 条件一次查询 Milvus 标量字段
- **去重封装**: 按 `image_path` 去重，返回标准 `RetrievalResult`

#### 主要类和方法

##### `CaptionToImageRetriever`

**方法（精简接口）**:
- `search_from_md_image_captions(md_captions: Union[str, List[str]], top_k_per_caption: int = 3, use_like: bool = True) -> Dict[str, Any]`

**返回字段**:
- `normalized_candidates`: 归一化后的查询候选短语列表
- `results`: List[RetrievalResult]，其中 `metadata.match_type` 为 `like_or`
- 每条结果的 `metadata.image_path/caption/source` 可用

**使用示例**:
```python
from UltrasoundRAG.retrival import create_caption_retriever

# 创建Caption检索器（使用默认数据库映射）
caption_retriever = create_caption_retriever(db_name="default")

# 直接用 MD 的 image_captions 列表/JSON 字符串进行匹配
md_caps = [
    "图1-2 眼前段中央区的UBM图像；图1-3 眼角及周边结构的UBM图像；图1-4 眼前段测量方法"
]
res = caption_retriever.search_from_md_image_captions(md_caps, top_k_per_caption=3, use_like=True)
print(res.get("normalized_candidates"))
for r in res.get("results", []):
    print(r.metadata.get("image_path"), (r.metadata.get("caption") or "")[:80])
```

### 3. 多数据库管理器 (MultiDatabaseManager)

#### 功能描述
支持多个数据库和集合的灵活配置，实现跨数据库检索和数据库路由。

#### 核心特性
- **多数据库支持**: 支持不同专业领域的数据分离
- **动态配置**: 支持运行时数据库配置
- **跨数据库检索**: 支持在多个数据库间检索
- **数据库统计**: 提供数据库使用统计和监控
- **智能路由**: 根据查询类型自动选择数据库

#### 主要类和方法

##### `DatabaseType` - 数据库类型枚举
```python
class DatabaseType(Enum):
    GENERAL = "general"           # 通用数据库
    SPECIALIZED = "specialized"   # 专门数据库
    EXPERIMENTAL = "experimental" # 实验数据库
    PRODUCTION = "production"     # 生产数据库
```

##### `DatabaseConfig` - 数据库配置（与实现对齐）
```python
@dataclass
class DatabaseConfig:
    name: str
    db_name: str
    text_collection: str
    image_collection: str
    db_type: DatabaseType = DatabaseType.GENERAL
    priority: int = 1            # 数值越高优先级越高
    enabled: bool = True         # 是否启用
    description: str = ""
    tags: List[str] = None
```

##### `MultiDatabaseManager`

**主要方法（与实现对齐）**:
- `create_retriever(db_name: str, retriever_type: str, **kwargs) -> Any`
- `search_single_database(db_name: str, retriever_type: str, query: Any, **kwargs) -> Dict[str, Any]`
- `search_multiple_databases(strategy: RetrievalStrategy, retriever_type: str, query: Any, **kwargs) -> Dict[str, Any]`
- `search_by_tags(tags: List[str], retriever_type: str, query: Any, **kwargs) -> Dict[str, Any]`
- `auto_select_databases(query: str, retriever_type: str, num_databases: int = 2) -> List[str]`
- `get_database_stats() -> Dict[str, Any]`

**使用示例**:
```python
from UltrasoundRAG.retrival import create_multi_database_manager, DatabaseConfig, DatabaseType

# 创建多数据库管理器
manager = create_multi_database_manager()

# 添加数据库配置
cardiac_config = DatabaseConfig(
    name="cardiac_db",
    db_name="cardiac_ultrasound",
    text_collection="cardiac_text",
    image_collection="cardiac_images",
    db_type=DatabaseType.SPECIALIZED,
    description="心脏超声专业数据库"
)
manager.add_database(cardiac_config)

# 单数据库检索（返回字典，包含 results/total_results 等）
result = manager.search_single_database("cardiac_db", "t2t", "心脏超声检查", top_k=10)
print(result.get("total_results"))
```

### 4. 融合策略模块 (FusionRetrievalManager)

#### 功能描述
实现复杂的检索策略和结果融合，提供高级的多模态检索功能。

#### 核心特性
- **复杂T2T策略**: 文本块检索 + 图片标题匹配
- **多策略融合**: 支持多种检索策略的结果融合
- **智能去重**: 基于内容相似度的智能去重
- **权重配置**: 可配置的融合权重
- **策略分解**: 提供检索策略的详细分解

#### 主要类和方法

##### `FusionConfig` - 融合配置（与实现对齐）
```python
@dataclass
class FusionConfig:
    top_k: int = 10                           # 返回结果数量
    enable_text_image_fusion: bool = True     # 是否启用文本-图片融合
    text_search_ratio: float = 0.7           # 文本检索比重
    image_caption_ratio: float = 0.3         # 图片caption检索比重
    enable_exact_title_match: bool = True     # 是否启用精确标题匹配
    text_weight: float = 0.6                 # 文本权重
    image_weight: float = 0.4                # 图像权重
    content_similarity_threshold: float = 0.8 # 内容相似度阈值
    enable_deduplication: bool = True         # 是否启用去重
    # —— 新增增强开关 ——
    enable_adaptive_weights: bool = True
    enable_domain_partition: bool = True
    enable_caption_enhancement: bool = True
    enable_multimodal_rerank: bool = True
    enable_smart_fusion: bool = True
    default_fusion_strategy: FusionStrategy = FusionStrategy.ADAPTIVE_SMART
    fallback_strategy: FusionStrategy = FusionStrategy.WEIGHTED_MERGE
    image_hint_boost: float = 0.3
    technical_text_boost: float = 0.2
```

##### `FusionRetrievalManager`

**主要方法**:
- `t2t_search(query: str, top_k: Optional[int] = None) -> Dict[str, Any]`
- `multimodal_search(query: str, fusion_strategy: str = "weighted") -> Dict[str, Any]`
- `search_with_strategy(query: str, strategy: T2TFusionStrategy) -> Dict[str, Any]`

**使用示例**:
```python
from UltrasoundRAG.retrival import create_fusion_retrieval_manager

# 创建融合检索管理器
fusion_manager = create_fusion_retrieval_manager(
    text_search_ratio=0.7,
    image_caption_ratio=0.3,
    enable_exact_title_match=True
)

# 复杂T2T检索（策略分解返回 text_block + image_caption 两路）
result = fusion_manager.t2t_search("心脏超声检查异常")
print(f"文本结果: {result['total_text_results']}")
print(f"图像结果: {result['total_image_results']}")
print(f"策略分解: {result['strategy_breakdown']}")

# 多模态融合检索（内部会进行融合 + 可选多模态重排）
multimodal_result = fusion_manager.multimodal_search(
    "肝脏囊肿诊断",
    fusion_strategy="weighted"
)
```

### 5. 重排序模块 (SimpleRerankManager / MultimodalReranker)

#### 功能描述
提供规则重排序和模型重排序，并在需要时进行多模态/混合重排序以优化最终 Top-K 的质量与相关性。

#### 核心特性
- **规则重排序**: 基于词汇重叠、长度惩罚、医学术语奖励等规则
- **模型重排序**: 基于CrossEncoder等重排序模型
- **智能策略选择**: 自动选择最适合的重排序策略
- **缓存机制**: 支持重排序结果缓存
- **性能优化**: 批量处理和内存优化

#### 主要类和方法

##### `RerankConfig` - 重排序配置
```python
@dataclass
class RerankConfig:
    algorithm: str = "rule_based"     # 算法类型: rule_based, model_based
    max_candidates: int = 50          # 最大候选结果数
    final_count: int = 20             # 最终返回结果数
    enable_cache: bool = True         # 是否启用缓存
    overlap_weight: float = 0.3       # 重叠权重
    length_weight: float = 0.1        # 长度权重
    position_weight: float = 0.1      # 位置权重
    medical_term_weight: float = 0.2  # 医学术语权重
```

##### `SimpleRerankManager`

**主要方法**:
- `rerank_results(query: str, results: List[RetrievalResult], top_k: Optional[int] = None) -> RerankResult`
- `rule_based_rerank(query: str, results: List[RetrievalResult]) -> List[RetrievalResult]`
- `model_based_rerank(query: str, results: List[RetrievalResult]) -> List[RetrievalResult]`

**使用示例**:
```python
from UltrasoundRAG.retrival import create_rerank_manager

# 创建重排序管理器
reranker = create_rerank_manager(
    algorithm="rule_based",
    max_candidates=50,
    final_count=20
)

# 执行重排序
rerank_result = reranker.rerank_results("心脏超声检查", search_results)
print(f"重排序完成: {rerank_result.algorithm_used}")
print(f"处理时间: {rerank_result.processing_time:.3f}s")
print(f"结果数量: {len(rerank_result.reranked_results)}")
```

##### `MultimodalReranker`

**功能**: 基于文本相似性、视觉相似性与跨模态一致性进行加权融合，并可结合规则与模型两种传统重排结果进行混合重排。

**关键配置**（`MultimodalRerankConfig`）:
- `mode`: `text_only` / `image_only` / `multimodal` / `hybrid`
- `top_k`: 最终返回结果数
- `semantic_weight`/`visual_weight`/`textual_weight`/`cross_modal_weight`
- `min_score_threshold`、`diversity_penalty`、`max_candidates`
- `enable_rule_based`、`enable_model_based`、`rule_weight`、`model_weight`

> 在 `T2T/T2I` 检索流程中，若开启多模态重排，系统将调用 `MultimodalReranker.rerank_results(query, results)` 完成最终重排序。

## 数据结构

### RetrievalResult - 检索结果统一数据结构（与 `retrival/data_structures.py` 保持一致）

```python
@dataclass
class RetrievalResult:
    doc_id: str                    # 文档ID
    content: str                   # 内容
    metadata: Dict[str, Any]       # 元数据
    score: float                   # 相关性分数
    retrieval_type: str            # 检索类型
    resource_collection: str = ""  # 数据来源集合
```

**检索类型（常见值示例）**:
- `t2t_enhanced` / `text_to_text`: 文本到文本
- `t2i_enhanced` / `text_to_image`: 文本到图像
- `image_to_text` / `caption_to_text` / `image_caption_to_text`: 图像到文本或由图像结果转成文本
- `image_to_image`: 图像到图像
- `caption_to_image`: 基于 caption 的图片匹配（如 `like_or`）

**元数据自动补充（`__post_init__`）**:
- 若 `retrieval_type` 属于 `text_to_image`/`image_to_image`/`exact_caption_match`，`metadata.result_type` 会设为 `image`
- 若 `retrieval_type` 属于 `text_to_text`/`image_to_text`/`image_caption_to_text`，`metadata.result_type` 会设为 `text`
- 若 `retrieval_type` 以 `image_` 开头，`metadata.query_type` 为 `image_query`；以 `text_` 开头为 `text_query`

## 使用示例

### 1. 基础检索使用

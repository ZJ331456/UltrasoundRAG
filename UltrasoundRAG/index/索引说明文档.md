# 索引构建系统说明文档 v2.0

## 概述

本索引构建系统是一个专为医学超声数据设计的**企业级双模态混合检索系统**，支持文本和图像两种数据类型的索引构建和检索。系统采用模块化设计，包含数据解析层和向量存储层，并集成了**统一异常处理、性能优化、安全机制和可观测性**等企业级功能，实现了高效、稳定、安全的文档和图像检索功能。

## 系统架构

```
数据源 → 解析器 → 向量化 → 存储到Milvus
  ↓        ↓        ↓         ↓
图像数据  图像解析器  FetalCLIP  图像集合
Markdown  文档解析器  双向量    文档集合
```

### 核心组件

1. **数据解析层** (`index/`)
   - `ImageParser`: 图像数据解析和向量化
   - `MarkdownParser`: Markdown文档智能分块和图片提取

2. **向量存储层** (`milvus/`)
   - `MilvusManager`: 向量数据库管理，支持 MD/PDF/Image 多集合架构

3. **安全保障层** (`utils/`)
   - `ExceptionHandler`: 统一异常处理和错误码管理
   - `SecurityManager`: API认证、授权和频率限制
   - `FileValidator`: 文件安全验证和格式检查

4. **性能优化层** (`utils/`)
   - `CacheManager`: 智能缓存系统和LRU策略
   - `BatchProcessor`: 高效批处理和异步执行
   - `SmartModelManager`: 智能模型生命周期管理

5. **监控观测层** (`utils/`)
   - `SystemMonitor`: 系统资源和性能监控
   - `HealthChecker`: 自动化健康检查和状态诊断
   - `AlertManager`: 智能告警和异常通知
   - `StructuredLogger`: 结构化日志和链路追踪

## 详细组件说明

### 1. 图像解析器 (ImageParser)

#### 功能描述
负责处理图像数据，使用FetalCLIP模型生成768维图像向量，为图像检索提供基础；同时可生成 caption 的 CLIP 文本向量（768维），便于下游使用。

#### 核心特性
- **模型支持**: 使用FetalCLIP模型，专门针对胎儿超声图像优化
- **容错机制**: 图像不存在时跳过，处理失败时使用零向量
- **批量处理**: 支持大量图像的批量向量化处理
- **进度跟踪**: 使用tqdm显示处理进度

#### 主要方法

##### `__init__(dataset_name: str = "ultrasound_book")`
初始化图像解析器，从配置文件加载相关参数。

**参数**:
- `dataset_name`: 数据集名称，默认为"ultrasound_book"

**配置项**:
- `base_image_path`: 图像基础路径
- `image_index_path`: 图像索引文件路径
- `model_path`: FetalCLIP模型路径
- `model_config_path`: 模型配置文件路径

##### `load_image_index() -> List[Dict]`
读取image_index.jsonl文件，返回图像数据列表。

**返回格式**:
```python
[
    {
        "image_path": "相对路径",
        "caption": "图像标题",
        "source": "来源（通常为文件夹名或数据域）"
    }
]
```

##### `generate_image_vector(image_path: str) -> Optional[List[float]]`
生成图像向量。

**处理流程**:
1. 检查图像文件是否存在
2. 使用PIL加载并转换为RGB格式
3. 通过FetalCLIP预处理
4. 模型编码生成768维向量
5. 维度校验和容错处理

**返回值**:
- 成功: 768维浮点数列表
- 文件不存在: None（跳过）
- 处理失败: 768维零向量

##### `parse_images() -> List[Dict]`
解析所有图像数据，返回标准化的数据格式。

**返回格式（与实现对齐）**:
```python
[
    {
        "id": 1,
        "image_path": "图像相对路径",
        "caption": "图像标题",
        "source": "来源",
        "image_vector": [0.0, ...] * 768,
        "caption_vector_clip_768": [0.0, ...] * 768
    }
]
```

#### 使用示例
```python
from UltrasoundRAG.index.image_parse import ImageParser

# 初始化解析器
parser = ImageParser(dataset_name="ultrasound_book")

# 解析所有图像
parsed_images = parser.parse_images()
print(f"成功解析 {len(parsed_images)} 张图像")
```

### 2. Markdown文档解析器 (MarkdownParser)

#### 功能描述
专门处理Markdown文档，进行智能分块和图片信息提取，为文档检索提供结构化数据。

#### 核心特性
- **智能分块**: 基于标题层级的语义分块
- **重叠窗口**: 支持块间重叠，保持语义连续性
- **图片提取**: 自动提取文档中的图片链接和标题
- **多语言支持**: 支持中英文标题模式识别

#### 主要方法

##### `__init__(dataset_name: str = "ultrasound_book")`
初始化Markdown解析器。

**配置项**:
- `base_md_path`: Markdown文件基础路径
- `max_chunk_size`: 最大块大小
- `overlap_ratio`: 重叠比例（默认10%）
- `min_chunk_size`: 最小块大小（默认100字符）

##### `get_markdown_files() -> List[str]`
递归获取所有.md文件。

##### `parse_markdowns() -> List[Dict]`
解析所有Markdown文件，返回处理后的文档块列表。

**返回格式**:
```python
[
    {
        "id": 1,
        "title": "文档标题",
        "content": "文档内容",
        "md_file": "相对文件路径",
        "document_name": "文档名称",
        "chunk_index": 0,
        "image_paths": ["图片链接1", "图片链接2"],
        "image_captions": ["图片标题1", "图片标题2"]
    }
]
```

##### `extract_title_and_content(text: str) -> List[Dict]`
提取文档的标题和内容块。

**分块策略**:
1. 按标题层级分块（#/##/###/####等）
2. 每个块分配对应的一级标题
3. 长内容进一步智能分割

##### `_split_long_content(content: str, title: str, base_index: int) -> List[Dict]`
智能分割长内容为小块。

**分割策略**:
1. 优先按段落(\n\n)分割
2. 其次按句号(。)分割
3. 支持重叠窗口，保持语义连续性
4. 智能选择分割点，避免截断重要信息

##### `extract_image_info(text: str) -> List[Tuple[str, str]]`
提取图片链接和标题信息。

**支持格式**:
- 中文标题: `图X-X 标题描述`
- 英文标题: `Figure X.X 标题描述`
- Markdown格式: `![](图片链接)`

#### 使用示例
```python
from UltrasoundRAG.index.markdown_parse import MarkdownParser

# 初始化解析器
parser = MarkdownParser(dataset_name="ultrasound_book")

# 解析所有Markdown文件
chunks = parser.parse_markdowns()
print(f"成功解析 {len(chunks)} 个文档块")
```

### 3. Milvus向量数据库管理器 (MilvusManager)

#### 功能描述
负责Milvus数据库的连接、集合管理、数据插入和搜索功能，支持MD文档和图片两个独立的集合。

#### 核心特性
- **双集合架构**: 支持MD文档集合和图像集合
- **多向量支持**: MD集合支持双向量（Qwen 1024维 + CLIP 768维）
- **分区支持**: 支持按领域(domain)分区存储
- **软删除**: 支持数据软删除，便于数据管理
- **多向量检索**: 支持多向量混合检索和权重融合

#### 主要方法

##### `__init__(milvus_uri, milvus_token, db_name, collection_type, ...)`
初始化Milvus管理器。

**参数**:
- `milvus_uri`: Milvus服务地址
- `milvus_token`: Milvus认证令牌
- `db_name`: 数据库名称
- `collection_type`: 集合类型（"md"或"image"）
- `enable_domain_partition`: 是否启用领域分区
- `domain_field_name`: 领域字段名称

##### `_setup_database()`
设置Milvus数据库，如果不存在则创建。

##### `_setup_collection()`
设置Milvus集合，根据集合类型创建相应的Schema和索引。

**MD文档集合Schema（与实现对齐）**:
```python
{

    "title": VARCHAR(512),                        # 标题
    "image_paths": VARCHAR(65535),                # 图片链接(JSON数组字符串)
    "image_captions": VARCHAR(65535),             # 图片标题(JSON数组字符串)
    "document_name": VARCHAR(256),                # 文档名称
    "chunk_index": INT64,                         # 块索引
    "domain": VARCHAR(128),                       # 领域分区

```

**PDF文档集合Schema（与实现对齐）**:
```python
{
    "id": INT64 (主键),
    "text_vector_qwen_1024": FLOAT_VECTOR(1024),
    "text_vector_clip_768": FLOAT_VECTOR(768),
    "content": VARCHAR(65535),
    "pdf_file": VARCHAR(512),
    "title": VARCHAR(512),
    "image_paths": VARCHAR(65535),
    "image_captions": VARCHAR(65535),
    "document_name": VARCHAR(256),
    "chunk_index": INT64,
    "page_start": INT64,
    "page_end": INT64,
    "domain": VARCHAR(128),
    "is_deleted": BOOL

```

**图像集合Schema（与实现对齐）**:
```python
{
    "id": INT64 (主键),
    "image_vector": FLOAT_VECTOR(768),            # 图像向量
    "caption_vector_clip_768": FLOAT_VECTOR(768), # Caption文本CLIP向量
    "image_path": VARCHAR(512),                   # 相对路径
    "caption": VARCHAR(65535),                    # 图像标题（按上限截断）
    "source": VARCHAR(256),                       # 来源
    "domain": VARCHAR(128),                       # 领域分区
    "is_deleted": BOOL                            # 软删除标记

```

##### `insert_data(data_list, embeddings=None, embeddings_qwen=None, embeddings_clip=None, domain_values=None, embeddings_caption_clip=None) -> bool`
插入数据到Milvus。

**参数**:
- `data_list`: 数据列表
- `embeddings`: 单向量（兼容旧版本；MD为文本/IMAGE为图像向量）
- `embeddings_qwen`: Qwen向量（1024维）
- `embeddings_clip`: CLIP向量（768维）
- `embeddings_caption_clip`: 图像caption的CLIP文本向量（768维，image集合可选）
- `domain_values`: 领域值列表

**特性**:
- 支持双向量插入
- 自动字段长度截断
- JSON字段规范化
- 维度校验和容错
- 领域分区支持

##### `search(query_embedding, top_k, filter_expr, partition_names) -> List[Dict]`
向量搜索。

**特性**:
- 自动向量维度检测
- 软删除过滤
- 领域分区过滤
- JSON字段解析

##### `search_multi_vectors(field_to_embedding, top_k, weights, filter_expr, partition_names) -> List[Dict]`
多向量混合检索。

**参数**:
- `field_to_embedding`: 字段到向量的映射
- `weights`: 各字段权重
- `filter_expr`: 过滤表达式
- `partition_names`: 分区名称列表

**融合策略**:
- 分别对各向量字段检索
- 按权重融合结果
- 去重和排序

##### `search_with_filter(filter_expr, limit, output_fields) -> List[Dict]`
基于标量过滤的查询。

##### `search_by_scalar_field(field_name, field_value, limit, output_fields) -> List[Dict]`
基于标量字段的精确匹配查询。

#### 使用示例

##### 初始化和管理
```python
from UltrasoundRAG.milvus.milvus_manager import MilvusManager

# 初始化MD文档集合管理器
md_manager = MilvusManager(collection_type="md")

# 初始化图像集合管理器
img_manager = MilvusManager(collection_type="image")
```

##### 数据插入
```python
# 插入MD文档数据
md_data = [
    {
        "id": 1,
        "content": "文档内容",
        "title": "文档标题",
        "md_file": "文件路径",
        "document_name": "文档名称",
        "chunk_index": 0
    }
]

# 双向量插入
qwen_vectors = [[0.1] * 1024]  # Qwen向量
clip_vectors = [[0.2] * 768]   # CLIP向量

success = md_manager.insert_data(
    data_list=md_data,
    embeddings_qwen=qwen_vectors,
    embeddings_clip=clip_vectors
)
```

##### 向量搜索
```python
# 单向量搜索
query_vector = [0.1] * 1024  # 1024维Qwen向量
results = md_manager.search(
    query_embedding=query_vector,
    top_k=5,
    filter_expr="title like '%超声%'"
)

# 多向量混合检索
field_to_embedding = {
    "text_vector_qwen_1024": qwen_vector,
    "text_vector_clip_768": clip_vector
}
weights = {
    "text_vector_qwen_1024": 0.7,
    "text_vector_clip_768": 0.3
}

results = md_manager.search_multi_vectors(
    field_to_embedding=field_to_embedding,
    weights=weights,
    top_k=5
)
```

## 索引构建流程

### 1. 图像索引构建

```python
# 1. 初始化图像解析器
image_parser = ImageParser(dataset_name="ultrasound_book")

# 2. 解析图像数据
parsed_images = image_parser.parse_images()

# 3. 提取向量
image_vectors = [img['image_vector'] for img in parsed_images]

# 4. 初始化Milvus管理器
img_manager = MilvusManager(collection_type="image")

# 5. 插入数据
success = img_manager.insert_data(
    data_list=parsed_images,
    embeddings=image_vectors
)
```

### 2. 文档索引构建

```python
# 1. 初始化文档解析器
md_parser = MarkdownParser(dataset_name="ultrasound_book")

# 2. 解析文档数据
parsed_chunks = md_parser.parse_markdowns()

# 3. 生成向量（需要额外的向量化步骤）
# 这里需要调用文本向量化模型
qwen_vectors = generate_qwen_vectors(parsed_chunks)
clip_vectors = generate_clip_vectors(parsed_chunks)

# 4. 初始化Milvus管理器
md_manager = MilvusManager(collection_type="md")

# 5. 插入数据
success = md_manager.insert_data(
    data_list=parsed_chunks,
    embeddings_qwen=qwen_vectors,
    embeddings_clip=clip_vectors
)
```

## 技术细节

- **FetalCLIP图像向量**: 768维
- **Qwen文本向量**: 1024维

### 索引类型
- **主键索引**: AUTOINDEX
- **向量索引**: HNSW + COSINE（文本/图像向量）
- **标量索引**: AUTOINDEX（标题、文档名、分区、删除标记等）

### 性能优化
